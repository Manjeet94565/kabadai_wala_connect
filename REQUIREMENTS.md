# Development requirements

This repository has separate frontend, backend, AI-service, database, and documentation modules. Read the `REQUIREMENTS.md` file inside the module you are assigned before starting work.

## Common tools

- Git
- Node.js 18 or later (Node.js 20 LTS recommended)
- npm
- Python 3.11 or later for `ai-service`
- PostgreSQL for backend/database work

## Module locations

| Module | Working directory | Setup guide |
| --- | --- | --- |
| Frontend | `frontend/frontend` | `frontend/REQUIREMENTS.md` or `frontend/frontend/REQUIREMENTS.md` |
| Backend | `backend` | `backend/REQUIREMENTS.md` |
| AI service | `ai-service` | `ai-service/REQUIREMENTS.md` |
| Database | `database` | `database/REQUIREMENTS.md` |
| Documentation | `docs` | `docs/REQUIREMENTS.md` |

Never commit `.env`, `node_modules`, Python virtual environments, database dumps, datasets, or model files.
