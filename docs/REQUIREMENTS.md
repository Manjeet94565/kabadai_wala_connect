# Documentation requirements

No package installation is required for this folder.

## Files to maintain

- `api-list.md`: API endpoint list
- `bug-list.md`: known issues and their status
- `test-cases.csv`: QA test cases
- `demo-script.md`: presentation/demo flow
- `deploy-backend.md`: Render backend deployment instructions
- `postman/`: exported Postman collections
- `source/`: approved reference material

Use clear Markdown and do not add passwords, tokens, personal data, or database dumps to documentation.
